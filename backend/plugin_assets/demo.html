Embedding the Centralized AI Assistant Widget

This demo page simulates an existing internal bank dashboard or intranet portal. Notice the floating blue shield icon in the bottom-right corner. It is running the embeddable chatbot plugin served directly by your Central FastAPI Gateway!

How to embed into any web portal:

Add these two lines inside the <head> and <body> of any existing website:

<!-- 1. Include CSS Stylesheet --> <link rel="stylesheet" href="http://<CENTRAL_GATEWAY_IP>:8001/plugin/widget.css"> <!-- 2. Include JS Widget Script --> <script src="http://<CENTRAL_GATEWAY_IP>:8001/plugin/widget.js" data-sbi-cms-gateway="http://<CENTRAL_GATEWAY_IP>:8001" data-auto-open="false"> </script>

No local Python, PyTorch, or Ollama installations required on client machines. All queries stream securely back to your central gateway server.
