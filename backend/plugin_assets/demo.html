SBI CMS Central Intelligence Floating Plugin

This page demonstrates how any existing SBI branch portal, intranet web app, or internal monitoring dashboard can embed the **AI Operations Chatbot** with a single <script> tag.

Notice the floating shield badge in the bottom-right corner. Click it to launch the embedded assistant!

1. HTML Integration Snippet

Copy and paste this snippet into the HTML of any internal website:

<!-- SBI CMS Embeddable AI Assistant Plugin --> <script src="http://<CENTRAL_GATEWAY_IP>:8001/plugin/widget.js" data-sbi-cms-gateway="http://<CENTRAL_GATEWAY_IP>:8001" data-auto-open="false" data-theme="dark" data-position="bottom-right"> </script>

2. Key Plugin Benefits

🔒 Zero Client-Side Software Needed

Client branch PCs do not need Python, PyTorch, or local Ollama installed. All AI reasoning and SQL queries run centrally on your gateway server.

🛡️ 100% Shadow DOM Style Isolation

The plugin renders inside an isolated Shadow DOM (`shadowRoot`). Host website styles will never break the widget UI.

🎨 Configurable Themes & Attributes

Supports data-theme (`dark` / `light`), data-position (`bottom-right` / `bottom-left`), and data-api-key for secure portal authentication.

⚡ Real-Time Data & NLP Text-to-SQL

Automatically queries live SQL Server telemetry for camera statuses, incidents, operator stats, and security alerts.
